Wallpepper GPU benchmark

A path tracer with a fixed workload, run on your graphics card by this browser. It draws the scene below at 3840 × 2160 for about ten seconds and turns the speed into a score.

    Reading the score
    
    
    The score is the number of megapixels drawn per second, scaled so that 10000 stands for 60 frames per
      second at 3840 × 2160. That is the estimate for an NVIDIA RTX 5090; until a real one has been measured,
      every score is labelled provisional.
    
    
    A browser adds work of its own between the page and the graphics card (in most browsers a translation
      layer called ANGLE). Scores from this page are therefore close to, but not strictly comparable with, the
      scores of the Wallpepper apps for Windows and Linux, which run the same workload without a browser.
    
    
    Close other tabs and programs that use the graphics card, and keep this tab in front while it runs.
